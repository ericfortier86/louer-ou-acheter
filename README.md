# Acheter ou louer? La question se pose!

Public buyer landing page for Eric Fortier, RE/MAX Direct, in Gatineau and the Outaouais.

- Custom domain: `louer-ou-acheter.eric-fortier.com`
- French: `/`; English: `/en/`
- GitHub Pages: `main`, root directory, with `.nojekyll`.
- Source: [`ericfortier86/ericfortier_remax/acheter-ou-louer`](https://github.com/ericfortier86/ericfortier_remax/tree/main/acheter-ou-louer).

This repository contains the exported public HTML, JavaScript, CSS and images. Edit the source project, then follow its `DEPLOIEMENT-GITHUB-PAGES.md` to rebuild, export and publish changes here. Cloudflare continues to handle the lead API and private D1 storage. No lead records or credentials are published in this repository.

The evaluation site remains in the original repository with its existing `evaluation.eric-fortier.com` Pages domain. Do not replace that domain with the buyer domain.

GoDaddy DNS for this site: CNAME `louer-ou-acheter` → `ericfortier86.github.io`. Keep the existing `evaluation` CNAME. After DNS validation and certificate issuance, enable **Enforce HTTPS** in this repository's Pages settings.
